# Hinweise zur Integration in die Startseite

Das Repository nutzt eine dynamische Startseite mit `data-view`-Abschnitten. Ergänzen Sie in `dist/index.html` die aktuelle Woche 43 als Link `href="woche-43.html"` und lassen Sie die bisherigen Wochen erhalten. Ändern Sie `dist/assets/portal.js` nicht. Das Deployment erfolgt im bestehenden Cloudflare-Projekt mit `wrangler.toml` und D1-Binding `DB`.

Für die produktive Website wurden die Verknüpfungen bereits über die GitHub-Verbindung ergänzt. Diese ZIP dient als zusätzliches Upload- und Sicherungspaket der neuen Unterrichtsseiten, nicht als vollständiger Ersatz für das bestehende Repository.
